# المختبرات

ستة عشر مختبرًا وحزمة يوم المشروع، كلها على جهة واحدة افتراضية: قُرب للرعاية الصحية عن بُعد. كل مختبر يعمل في جدول
بيانات (LibreOffice Calc أو Excel أو Google Sheets) أو أداة رسم أو نص مكتوب، على حاسوب محمول، دون تثبيت ودون
مفتاح لأي خدمة. لا يستدعي أي مختبر نموذج ذكاء اصطناعي.

## قاعدة الذكاء الاصطناعي

ملفات الحالة مصنفة «مقيد» في سجل قُرب، وقُرب تتبنى قاعدة مبادئ الذكاء الاصطناعي التوليدي للجهات الحكومية: لا يدخل
شيء مصنف «مقيد» أو أعلى أي أداة ذكاء اصطناعي توليدي. لذلك:

| الوضع | أين | ما يُسمح به |
|---|---|---|
| دون مساعد | 1.4 (المواقف)، 2.2، والاختبار الإشرافي | لا شيء |
| مساعد قراءة | 1.2، 2.3، 3.1، 3.4، 4.1، 4.3 | رفع النصوص الرسمية المنشورة وسؤاله عنها؛ لا شيء من ملفات الحالة |
| مساعد صياغة | 4.2، ومحاكاة يوم المشروع | وصف عام بكلمات المشارك، بلا أسماء ولا أرقام؛ ويستعمل المقرر بديلًا مكتوبًا مسبقًا لما يعيده المساعد، فيه أخطاء مقصودة |

باقي المختبرات لا تحتاج مساعدًا.

نطاق التوثيق `203.0.113.0/24`، والبريد على النطاق المحجوز `qurb.example`. جهات العمل المتعاقدة بأسماء محايدة
(جهة العمل E1 إلى E8). مدد الاحتفاظ في `retention_rules.txt` افتراض للحالة، لا قواعد حقيقية.

## إعادة التوليد والتحقق

يحتاج [uv](https://docs.astral.sh/uv/)، ويثبت `openpyxl` وحده في بيئة مؤقتة:

```
uv run labs/_tools/prepare_files.py      # يكتب labs/files/ وlabs/solutions/reference/ ببذرة ثابتة (206)
uv run labs/_tools/write_solutions.py    # يكتب labs/solutions/D*.md من المفاتيح
uv run labs/solutions/check.py           # يعيد حساب كل رقم من الملفات ويطابقه بالمفتاح
uv run labs/solutions/check.py 3.2 4.3   # مختبرات بعينها
```

التوليد حتمي: تشغيله مرتين يعطي الملفات نفسها بايتًا ببايت. `check.py` لا يكتب شيئًا، ويطبع الأرقام التي تذكرها
شرائح ما بعد المختبر، وPASS لكل مختبر.

## الحلول

`solutions/` للمدرب: حل مرجعي لكل مختبر (`D1_1.md` إلى `D4_4.md`)، ومفتاح يوم المشروع والوقائع الجديدة
(`capstone.md`)، والمفاتيح التي يتحقق منها `check.py` (`reference/`). نسخة المشاركين من الموقع تُبنى دونها
(`academy build --audience trainee`).
